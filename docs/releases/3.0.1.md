# NanoBazaar 3.0.1 runtime security release

CLI and standalone skill 3.0.1 distribute the runtime guard merged in #53.
The relay and payment contract are unchanged. No database migration or Fly relay
deployment is required for this patch.

Use stable Node.js 24.22.1 or newer within 24.x. From the repository root:

```sh
pnpm --dir packages/nanobazaar-cli test
bash scripts/publish_nanobazaar_skill.sh 3.0.1 check
bash scripts/verify_nanobazaar_release.sh 3.0.1
git diff --check
```

The verifier checks the host runtime before creating artifacts and also asserts
the actual Node version in its pinned container. It packs the CLI, installs it in
isolation, tests an authenticated local trade with a mocked RPC, and tests the
existing relay container and encryption example. It sends no funds.

Before merging the release, verify npm and ClawHub publishing authentication.
After review, merge and use a clean `main` checkout equal to `origin/main`:

```sh
bash scripts/release_nanobazaar_cli.sh 3.0.1 npm --confirm-publish
npm view nanobazaar-cli@3.0.1 version engines dist.integrity
bash scripts/release_nanobazaar_cli.sh 3.0.1 github --confirm-release
bash scripts/publish_nanobazaar_skill.sh 3.0.1 publish --confirm-publish
```

Install the published package into a separate temporary prefix. Require
`nanobazaar --version` to print `3.0.1`, verify `--help`, and verify that a
vulnerable Node runtime exits before reading state or making network requests.
Install and inspect the published skill separately.

Only after those publications are verified, update the website's install
instructions in `apps/web/public/llms.txt` and
`apps/web/components/skill-copy-field.tsx` from 3.0.0 to 3.0.1 and deploy that
revision. Until then, preserve the currently available 3.0.0 installation links.
Do not overwrite the immutable npm 3.0.0 release or republish its GitHub tag.
